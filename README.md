ImGui-Discord-Hooks
A collection of personal, experimental Discord client hook projects written in C++.
This repository contains scratched / work-in-progress implementations that inject and overlay ImGui-based interfaces into the Discord desktop client. The focus is on clean injection techniques, UI rendering with Dear ImGui, and basic feature prototyping rather than polished, production-ready tools.
What’s inside

Multiple small hook experiments and prototypes
ImGui rendering layer for Discord
Injection and memory-related utilities
Example overlays and simple interactive panels

Notes
These are personal learning / research projects. They are incomplete, may break with Discord updates, and are provided as-is for educational purposes only. Use at your own risk.
